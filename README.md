# Camera Roll to Vlog

**Camera Roll to Vlog - 写真フォルダからはじめる動画編集** は、スマホに残っている写真や動画を使って、Premiere Pro初心者が短い縦型Vlogを作れるようにする学習サイトです。

## 概要

このサイトは、Premiere Proの機能を網羅的に説明するサイトではありません。

写真フォルダに残っている思い出を、1本のVlog / short動画にまとめるまでの流れを、初心者が作業しながら確認できるようにすることを目的としています。

## コンセプト

スマホに残っている写真、旅行の動画、帰り道の空、友達との何気ない時間。

それらをPremiere Proで短いVlogに変えるための、作業しながら見られる伴走型レッスンサイトです。

## 想定ユーザー

- スマホで写真や動画をよく撮る人
- 旅行や日常の思い出を動画にまとめたい人
- Premiere Proを初めて触る人
- 動画を見ながら作業するのが苦手な人
- 自分のペースで文字を読みながら進めたい人
- スマホでサイトを見ながらPCで編集したい人

## ページ構成

```text
index.html
トップページ

lesson.html
全レッスンを1ページにまとめた作業用ページ

faq.html
よくある質問・レスキュー・用語集ページ
```

## レッスン構成

```text
LESSON 01　今日つくるVlogを決める
LESSON 02　写真フォルダから素材を選ぶ
LESSON 03　Premiere Proに素材を読み込む
LESSON 04　タイムラインに並べて流れを作る
LESSON 05　BGM・文字・色で“いい感じ”に整える
LESSON 06　書き出して、完成したVlogを見返す
```

## 主な機能

- レッスンの現在地表示
- 現在見ているレッスンに応じた自動進捗表示
- コース目次
- ショートカット一覧モーダル
- FAQ / レスキューのアコーディオン
- スマホ対応レイアウト
- 画像・GIF差し替え用のダミー枠

## 技術構成

- HTML
- CSS
- JavaScript

フレームワークやビルドツールは使用していません。
